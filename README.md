# Анализ отмен бронирований в отелях

## Цель
Понять, почему в отелях высокая доля отмен бронирований, и найти факторы, которые сильнее всего на это влияют.

## Данные
Использован открытый датасет Hotel Booking Demand (Kaggle).  
~119 тысяч бронирований двух отелей (City и Resort) за 2015–2017 годы.

## Основные выводы

1. **Канал бронирования Groups**  
   В канале Groups доля отмен значительно выше, чем в остальных каналах (разница около 28–29 п.п.).

2. **Lead time (за сколько дней бронировали)**  
   Чем раньше сделано бронирование, тем выше вероятность отмены.  
   - 0–7 дней: менее 10% отмен  
   - 91–180 дней: около 35% отмен  

3. **Тип депозита**  
   В данных обнаружена аномалия: у невозвратного тарифа (Non Refund) доля отмен почти 100%. Это противоречит логике и, скорее всего, связано с особенностями датасета. Поэтому основной анализ проводился без этой группы.

## Рекомендации
- Для бронирований с большим lead time (более 90 дней) рассмотреть введение предоплаты.
- Отдельно анализировать и контролировать бронирования из канала Groups.
